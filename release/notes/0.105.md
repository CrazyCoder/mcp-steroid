## 0.105

### MCP clients on older protocol revisions connect

- The server negotiates the MCP protocol version on `initialize`: it answers with the client's requested revision when it supports it (2025-11-25, 2025-06-18 or 2025-03-26), and with its latest otherwise. It always answered 2025-11-25 before, so clients that accept only older revisions, such as the Junie MCP client, closed the connection before any `steroid_*` tool was available. The HTTP transport reports the negotiated version in the `MCP-Protocol-Version` header. The change is Matvei Ludzskii's [jonnyzzz/mcp-steroid#483](https://github.com/jonnyzzz/mcp-steroid/pull/483), for [jonnyzzz/mcp-steroid#482](https://github.com/jonnyzzz/mcp-steroid/issues/482).
