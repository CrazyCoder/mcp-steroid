## 0.123

`runHighlightingPasses(file)` returns a file's highlights without an editor, a window or focus. It works on a Split Mode backend, where `getHighlightsWhenReady` never completes.

### Highlights without a window

- `runHighlightingPasses(file, minSeverityValue, timeout)` runs the editor's main passes with the project's inspection profile, as the IDE's own `lint_files` MCP tool does. It includes the unused-symbol pass that `runInspectionsDirectly` does not run.
- The analysis gives way to write actions and then runs again. It returns the highlights in document order.
- A timeout or a cancelled script stops the analysis and returns an empty list with a warning.
- When `waitForEditorHighlighting` times out, or the file is not open in an editor, the warning names `runHighlightingPasses`. On a Split Mode backend it also says that focus cannot help.

### Fixes

- In a script, `::println` is `kotlin.io.println`, which writes to the IDE's stdout and not to the result. The Spring and threading recipes use `{ println(it) }`, and the context API and PSI prompts warn about `::println`.
