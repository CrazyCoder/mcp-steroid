## 0.111

This release makes marked screenshots cover what 0.110 left out, and lets an agent work through long pages without reading every control on them.

### Marked screenshots: rows, tabs and popups

- Every row of a list, tree or table in view, and every tab, is labelled with a row ref such as `e91#9`, at the row's right end. It is row `#9` of the control `[ref=e91]`, as a snapshot lists it. `select`, `click`, `hover`, `scroll` and `inspect` take it as their `ref`, so a Settings category, a project tree node or a table row seen in the picture is one step away: `{"action":"select","ref":"e91#9"}`. `click` presses the row itself, which a double click to open a row needs.
- An open combo box popup labels its items with the combo box's ref, and `select` on one picks the item and closes the popup.
- A control that a popup covers is no longer outlined on top of the popup.
- The group name the Settings tree keeps at the top while it scrolls no longer carries the label of the row under it.

### steroid_ui

- `select` with a tree path such as `Editor > Code Style > Java` expands the collapsed parents, as a user would. It waits for trees that load their children in the background.
- A tabbed pane, such as the Marketplace and Installed tabs on the Plugins page, lists its tabs as rows, and `select` switches between them. A click on a tabbed pane by its name presses that tab.
- A new `scroll` step brings a control or a row into view: `{"action":"scroll","name":"Gherkin"}`. With `"pages"` it pages the scroll pane around the target, reports which part of the content shows, and the response lists the controls that came into view.
- A snapshot lists the controls a long scroll pane shows and counts the rest on one line, such as `… 1283 below scrolled out of view`. The snapshot of the Plugins page drops from about 1,300 controls to the 35 in view. Steps still find the hidden controls by name or text and scroll them into view themselves.

### Release assets

The plugin zip is attached once, as `mcp-steroid-plus-<version>.zip`, with its `.sha256`. `release.json` names it, so JetDesk and other clients that read `release.json` follow without a change.
