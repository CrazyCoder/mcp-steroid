## 0.108

### Keyboard and mouse shortcuts work in `steroid_input`

- `press:` steps now run keymap shortcuts. A shortcut such as `press:META+1` or `press:CTRL+SHIFT+A` runs its action. Keys go through the IDE event queue, the same path Remote Development uses for client keystrokes, so the IDE matches them against the keymap before the focused component gets them ([#1](https://github.com/CrazyCoder/mcp-steroid/issues/1)).
- `click:` steps now run keymap mouse shortcuts too. For example, `click:CTRL+Left` on a reference runs Go to Declaration. Clicks still reach the component under the pointer.
- The response lists the IDE actions that ran during the sequence, for example `IDE actions performed: GotoDeclaration`, or says that none ran. It no longer reports success for a shortcut that did nothing.
