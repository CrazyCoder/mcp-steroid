## 0.104

### Updates inside the IDE

- MCP Steroid Plus now updates through the IDE's own plugin update check. The plugin adds the latest GitHub release's `updatePlugins.xml` to the plugin repositories the IDE reads, so a new release shows up in the IDE's standard plugin update notification and installs on restart. Automatic plugin updates apply when they are turned on.
- The plugin's own "update available" notification is removed, together with the `mcp.steroid.updates.enabled` registry key. It only linked to the release page.
- This applies from 0.104 on. An IDE with 0.103 needs one manual install of 0.104 from the release page, and updates in the IDE after that.
