## 0.118

Tool results now tell the agent about the IDE's notifications and about the errors in open editors. `steroid_ui` closes the floating Settings window of 2026.3, and a `settings` step no longer stacks a second Settings dialog.

### Notifications and editor errors

- Tool results start with an `IDE NOTIFICATIONS` notice when the IDE showed notifications since the previous call. It lists errors and warnings first, at most three, with their actions. When one has an action, the notice says how to click it in the Notifications tool window. In Split Mode the JetBrains Client names them, the backend's included, so each one is told once.
- Tool results start with an `EDITOR ERRORS` notice when an open file shows an error the session was not told about. It gives each file's error count and its first error, for at most three files. An error that only moved to another line is not told again. In Split Mode the notice comes from the backend, with a call that reaches it, such as `steroid_execute_code`.
- `{"action":"get","problems":"src/A.kt"}` lists the errors the editor highlights in an open file as `path:line:column: SEVERITY text`, and `"problems":true` lists them for every open file. `"severity":"warning"`, `"weak_warning"` or `"info"` adds the lower levels. The step waits for the analysis of the files whose tabs show, and names the files not analyzed to the end. A closed file fails with the `goto` that opens it.
- `{"action":"get","notifications":true}` lists the recent notifications with their actions.

### Settings and closing windows

- `close` closes the floating Settings window, which 2026.3 opens by default. It is a plain dialog that no DialogWrapper holds, and `close` refused it before (#2).
- `close` fails when the window is still open afterwards and opened nothing, such as a confirmation. Before, it reported such a window as closed.
- A `settings` step with a modal Settings dialog open switches that dialog to the page. Before, the IDE opened a second modal Settings dialog over it. A page the open dialog cannot show fails and says to close the dialog first.
