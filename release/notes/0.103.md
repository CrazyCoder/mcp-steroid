## 0.103

The first release of MCP Steroid Plus, a maintained fork of the MCP Steroid IDE plugin. It is based on MCP Steroid 0.102 and installs next to it under its own plugin ID.

### Identity and updates

- The plugin ID is `io.github.crazycoder.mcp-steroid` and it installs into `plugins/mcp-steroid-plus`. An upstream Marketplace install cannot delete it, because the IDE clears only the folder of the plugin it installs.
- When the upstream MCP Steroid plugin is also installed, MCP Steroid Plus disables it and asks for an IDE restart. Until the restart both run, and MCP Steroid Plus takes the next free port.
- Registry keys, `~/.mcp-steroid`, the marker files and the MCP server name are unchanged, so existing clients and settings keep working.
- The update check reads `release.json` from the latest GitHub release of this fork, and the notification links the release page.
- Analytics are off by default. The settings page shows the direct HTTP connection only.

### Port pins

- The server takes its port from `~/.mcp-steroid/ports.json` when the file pins the IDE's plugins directory to a port. A pin wins over the `mcp.steroid.server.port` registry value, which applies when there is no pin.
- A running IDE moves its server to a changed pin within a few seconds, without a restart. If every port in the pinned range is busy, the server stays on its current port.

### Fixes

- `steroid_execute_code` works on IntelliJ Platform 263 nightlies again. The plugin bundles jackson-databind, which 263 no longer exposes to non-bundled plugins.
